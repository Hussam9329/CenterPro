# CenterPro — مراجعة الريفاكتور

## الحالة

اكتمل تنفيذ الريفاكتور والتحقق منه محلياً على الفرع `refactor/centerpro-maintainability` انطلاقاً من `4ee5ef8c5761ec5d89846febc736741d26adf8f6`. النسخة جاهزة لموافقة الرفع والنشر.

لم يُرفع أي commit إلى GitHub، ولم يُنفّذ نشر على Vercel أو اتصال بقاعدة بيانات Production. النشر يتطلب موافقة صاحب المشروع بعد اكتمال التحقق، وفق طلبه الأخير.

**تحديث الموافقة:** بعد مراجعة هذا التقرير وتوضيح تفاصيل الريفاكتور، وافق صاحب المشروع بتاريخ ١٥ أكتوبر ٢٠٢٦، الساعة ٠٣:٢٤ بتوقيت بغداد: «تمام ارفع». أُجيز رفع النسخة المختبرة إلى `main` ونشرها على Vercel Production. وصف عدم الرفع أعلاه يوثق حالة التسليم قبل الموافقة؛ نجاح النشر يُثبت لاحقاً من CI وVercel وفحص الرابط الفعلي.

## ما تغير

- فصل محرك تعديلات السيرفر إلى وحدات التحقق، الموظفين، الحضور، الرواتب، التدقيق، الحذف وسجل العمليات، مع الحفاظ على ترتيب تنفيذها.
- فصل الجلسات وتسجيل الدخول وحدود المحاولات ومعاملات الحفظ ومستودع البيانات إلى وحدات مستقلة خلف نفس واجهات الاستيراد.
- فصل موفر بيانات الواجهة إلى تخزين محلي، طلبات HTTP، تحديث اللقطة، حماية الجلسات، تتبع المسودات المتعارضة والتنبيهات.
- فصل حسابات الرواتب وقواعد التقويم والأرشيف ومصدر الشهر ونماذج التقارير عن مكونات العرض. أزيل اعتماد السيرفر على مكونات مالية من React.
- تنظيم التقييمات والرتب والمجاميع واللقطات التاريخية، وفصل الحفظ التلقائي واختيار الموظفين عن شاشة المدقق.
- فصل مراجعة الحضور ونوافذ اليوم ونموذج الموظف وتعديل كلمة المرور ودورة حياة كاميرا QR وتجديد الرمز.
- تنظيم مسودات الإعدادات وحساب شاشة الحضور وتنزيل النسخة الاحتياطية، مع استمرار استقلال نماذج الحفظ والإلغاء.
- فصل مكونات UI المشتركة وقواعد التنقل والصلاحيات في غلاف التطبيق. قُسّمت الأنماط العامة إلى ملفات مرتبة دون تغيير الـcascade.
- إضافة ٨ اختبارات لنماذج التقارير و٩ اختبارات لقواعد التنقل والصلاحيات، مع إبقاء الاختبارات السابقة.

تفاصيل حدود الوحدات وقواعد الحفاظ على السلوك موجودة في [REFACTOR.md](REFACTOR.md).

المجموع: **٥٢٤ اختباراً ناجحاً**. لم تُعطّل أو تُحذف اختبارات سابقة لتجاوز أي فحص.

تستخدم اختبارات PostgreSQL محرك PGlite مع ملفات الهجرة الموجودة. تستخدم اختبارات المتصفح بيانات مصطنعة؛ اختبارات محول الخادم تضبط استجابات HTTP. لا تستعمل هذه الفحوصات Neon الحقيقي أو حسابات المركز.

أُعيد تشغيل `npm run check` بنجاح بعد حفظ تغييرات الكود في `2c1b2fb`، ثم نُفّذ بناء منفصل بوضع الخادم. لم تتغير ملفات الكود أو الاختبارات بعد هذه النقطة؛ آخر commit مخصص لهذا التقرير ووثائق حدود الريفاكتور.

## المقارنة مع النسخة الأصلية

| المقارنة | النتيجة |
| --- | --- |
| محرك التعديلات على السيرفر | ٣٬٧١٢ حالة متطابقة في ١٢ مجالاً؛ تمت مقارنة الناتج والأخطاء وعدم تغيير المدخلات، مع توحيد UUID المولد فقط |
| نماذج التقارير | ٢٩٤ سيناريو مطابقاً دون تعديل بيانات المدخلات |
| غلاف التطبيق والتنقل | HTML مطابق في ٥٬١٨٤ تركيبة للصلاحيات والمسارات والثيم وحالة الجلسة والقائمة والاتصال |
| ملفات CSS الناتجة من البناء | الملفات السبعة مطابقة بايتاً ببايت |
| لقطات الواجهة قبل/بعد | ٤٢ زوجاً مطابقاً بكسل ببكسل؛ لا أخطاء JavaScript أو تجاوز أفقي في هذه اللقطات |

شملت اللقطات: لوحة الإدارة، تفاصيل الحضور ونافذة المراجعة، نموذج الموظف، الرواتب، الإعدادات، سجل العمليات، التقارير، صفحة الموظف، نتائجه وشاشة المدقق. المقاسات: `1366×900` فاتح، `768×1024` داكن، `390×844` فاتح وداكن.

راجعت المقارنة المستقلة أجسام الدوال المنقولة في المصادقة ومستودع البيانات والرواتب والتقييمات ومكونات UI. بقيت حماية المسودات المنفصلة، ترتيب إلغاء الجلسات، نافذة مراجعة الحضور المستمرة، تأكيد الحذف، طابور الحفظ التلقائي والمؤقتات دون تغيير.

## الأثر على البيانات والتشغيل

- لا تعديل لقواعد Business Logic أو SQL schema أو ملفات الهجرة أو بروتوكول API.
- لا تغيير للحزم أو ملف القفل أو أصول الهوية البصرية أو صيغة النسخ الاحتياطية.
- لا حاجة إلى Environment Variables جديدة أو إعادة استيراد البيانات.
- لم يُنفّذ import أو reset أو migration أو اختبار على بيانات المركز.
- هذه نتائج اختبارات محلية ومقاسات متصفح محاكاة؛ التحقق من نشر Vercel وNeon الفعلي يبقى جزءاً من خطوة النشر بعد الموافقة.
